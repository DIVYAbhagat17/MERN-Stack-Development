## 🧩 Understanding the MERN Stack

<div align="center">
  <img src="https://skillicons.dev/icons?i=mongodb,express,react,nodejs" alt="MongoDB, Express.js, React.js, and Node.js icons" />
</div>

- **MongoDB:** Stores application data in a flexible document-based database.
- **Express.js:** Helps build backend routes and APIs.
- **React.js:** Creates interactive user interfaces.
- **Node.js:** Runs JavaScript on the server.
- **JavaScript:** Connects programming concepts across the frontend and backend.

- [ ] **JavaScript:** Variables, functions, arrays, objects, ES6+, and DOM.

- [ ] **Express.js:** Routing, middleware, and REST APIs.
- [ ] **MongoDB:** CRUD operations, queries, and database integration.
- [ ] **React.js:** Components, props, state, hooks, and routing.
- [ ] **MERN Integration:** Connect frontend, backend, and database.
- [ ] **Projects:** Build and document full-stack applications.
